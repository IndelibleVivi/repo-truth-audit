# Repository Operational Truth Audit v0.1.0

[简体中文](v0.1.0.zh-CN.md)

`v0.1.0` is the first public release of the standalone Repository Operational
Truth Audit Codex Skill.

## What ships

- A decision-bounded, topology-first, read-only audit workflow for repository
  re-entry, migration, consolidation, safe archive, handoff, and release
  readiness.
- Explicit source, generated artifact, installed/deployed identity, runtime,
  and owner-acceptance proof layers.
- Finding traces that connect a claim or live surface to mechanism/state,
  contradiction or evidence gap, decision impact, and fresh validation.
- False-green challenges, intentional-multiplicity versus shadow-path
  adjudication, external-unknown handling, fixed-point stopping, and end re-pin.
- Six synthetic controlled cases and deterministic fixture self-tests.
- A transactional local installer with provenance and recoverable replacement.
- Separate English and Simplified Chinese documentation editions.
- Separate day-first English and Chinese SVG architecture artifacts generated
  from one renderer-neutral semantic model.

## Install

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/skill-installer/scripts/install-skill-from-github.py" \
  --repo IndelibleVivi/repository-operational-truth-audit \
  --path skills/repository-operational-truth-audit \
  --ref v0.1.0
```

The canonical source is the tagged repository path. The installed directory is
a derived deployment; installation, next-turn Codex discovery, and successful
use remain separate observable boundaries.

## Deliberate limits

The Skill is not a code-review replacement, generic hygiene checklist, score,
compliance scanner, automatic repair workflow, default audit backlog, or
permission to inspect or mutate live external systems. A run remains read-only
unless a separate, explicit task authorizes a later implementation boundary.
