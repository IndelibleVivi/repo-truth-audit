# Repository Operational Truth Audit v0.1.0

[English](v0.1.0.md)

`v0.1.0` 是 standalone Repository Operational Truth Audit Codex Skill 的第一个
public release。

## 发布内容

- 面向 repository re-entry、migration、consolidation、safe archive、handoff 与
  release readiness 的 decision-bounded、topology-first、read-only audit workflow。
- 显式分开的 source、generated artifact、installed/deployed identity、runtime 与
  owner-acceptance proof layers。
- 把 claim 或 live surface 与 mechanism/state、contradiction 或 evidence gap、decision
  impact、fresh validation 连接起来的 finding trace。
- False-green challenge、intentional-multiplicity 与 shadow-path adjudication、
  external-unknown handling、fixed-point stopping 与 end re-pin。
- 六个 synthetic controlled cases 与 deterministic fixture self-tests。
- 带 provenance 与 recoverable replacement 的 transactional local installer。
- 分开的 English 与简体中文 documentation editions。
- 从同一 renderer-neutral semantic model 生成、分开的 day-first English 与中文 SVG
  architecture artifacts。

## 安装

```bash
python3 "${CODEX_HOME:-$HOME/.codex}/skills/.system/skill-installer/scripts/install-skill-from-github.py" \
  --repo IndelibleVivi/repository-operational-truth-audit \
  --path skills/repository-operational-truth-audit \
  --ref v0.1.0
```

Canonical source 是 tagged repository path。Installed directory 是 derived
deployment；installation、next-turn Codex discovery 与 successful use 是彼此分开的
observable boundaries。
