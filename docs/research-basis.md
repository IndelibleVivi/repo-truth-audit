# Research basis and provenance

[简体中文](research-basis.zh-CN.md)

Status: public-safe synthesis of the 2026-08-30 pre-spec research. The full raw
research packet and private repository evidence remain outside this repository.

## Product-form decision

The research accepted `DISTINCT_SKILL_HYPOTHESIS_SUPPORTED`: a recurring
topology-first behavior produced decision-material findings or unknowns across
structurally different repositories, retained a short clean control, and had a
stable boundary from bounded code review and one-claim verification.

Evidence classes included:

- private infrastructure re-entry with a presence-only safety gate;
- source/generated/installed Skill identity and provenance;
- a local-first product whose durable agent instructions drifted from current
  product authority;
- an intentionally split stable-release/current-development clean control;
- a controlled source-green/distribution-stale package fixture.

No private raw evidence, account data, host addresses, or local user paths are
carried into this repository.

## Negative controls

The product rejects lens explosion, multi-agent audit panels, automatic
worktree fixers, maturity scoring, permanent target-repository audit backlogs,
and broad specialist scans that are unrelated to the current owner decision.

## Independence boundary

Softpowers supplied the comparison baseline for review and verification, but it
does not own this product. Skill Field Lab may run controlled subject cases, but
it is optional evaluation infrastructure and not a runtime dependency.
